このサイトを作り始めた経緯と、構成についてのメモです。

## 使っている技術

- HTML / CSS / JavaScript（素の状態、フレームワークなし）
- ブログ部分だけ Jekyll（GitHub Pagesに標準で組み込まれている静的サイト生成ツール）
- ホスティングは GitHub Pages

## この記事の書き方

このファイルのように、`_posts/` フォルダに `年-月-日-タイトル.md` という名前でMarkdownファイルを追加するだけで、
`blog.html` の一覧に自動的に表示されます。一覧ページのHTMLは書き換える必要がありません。
